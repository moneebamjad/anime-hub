# Anime Hub — Search-Driven Content Clusters

## Publishing model
Build topical authority around a manageable set of franchises. Each franchise should have one strong hub and a connected set of articles covering distinct search intents. Avoid publishing near-duplicate pages just to increase URL count.

## High-value search intents
For each franchise, prioritize distinct intent clusters such as:
- watch order
- arcs in order
- filler list
- characters explained
- powers / abilities / rankings
- ending or story explained
- anime vs manga
- episode guides
- release / season information when verified
- strongest characters
- major current news only when supported by reliable sources

## Internal-link rule
Every article should link to:
1. Its franchise hub.
2. At least two closely related articles.
3. The relevant category page.
4. A useful next article when the search intent naturally continues.

Franchise hubs should link back to their strongest evergreen guides and selected current stories.

## Editorial rule
Do not mass-produce generic AI articles. Every article should satisfy a specific search intent, answer the query directly near the top, add original organization/context, cite authoritative or primary sources where appropriate, and be updated when the underlying information changes.
